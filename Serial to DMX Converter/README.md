An ATMega8 based device to convert an incoming UART data stream (57600 BAUD) from the Halloween control board into DMX output using DMXSimple. This device uses a header ID of 0xA0 to align with the Header framing of the existing Serial bus.

The enclosure files provide non isolated 12V input and serial data, with two DMX output. This is not a good configuration long term and will be replaced
